🛠️ Standard Secret Remediation Protocol

  1. Revoke & Rotate: The leaked credential must be revoked immediately in the provider console. Deleting code does not revoke exposed API tokens.
  2. Purge Git History: Run git-filter-repo --replace-text <(echo "LEAKED_KEY==>REDACTED") and force-push.
  3. Adopt 12-Factor Injection: Move credentials to .env for local development and HashiCorp Vault or GitHub Secrets for CI/CD and production.
  4. Guard Container Images: Never use ENV SECRET=... or COPY .env inside Dockerfiles. Keep .dockerignore strictly maintained.
